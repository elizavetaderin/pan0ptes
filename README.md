# pan0ptes
PANOPTES

Siber Güvenlik Projesi

PANOPTES, C++ kullanılarak geliştirilen başlangıç seviyesinde bir siber güvenlik projesidir.

Projenin amacı, kullanıcıların internette karşılaştıkları şüpheli durumları kaydetmelerine ve daha sonra incelemelerine yardımcı olmaktır.

Özellikler

* Yeni olay kaydetme
* Kaydedilen olayları görüntüleme
* Kullanıcı adına göre arama yapma
* Şüpheli bağlantıları temel düzeyde kontrol etme
* Başarısız giriş denemelerini değerlendirme

Kullanılan Teknolojiler

* C++
* C++17
* Visual Studio Code

Projenin Amacı

Bu projeyi C++ programlama dilini öğrenmek ve siber güvenlik alanında kendimi geliştirmek amacıyla hazırlıyorum.

PANOPTES şu anda geliştirme aşamasındadır.

Gelecek Hedefleri

* Yeni özellikler eklemek
* Bağlantı kontrollerini geliştirmek
* Programı daha kullanışlı hâle getirmek
